# Reference results

All figures come from `analysis/reference_sensitivities.csv`, regenerated by

```powershell
uv run python scripts/run_reference_sensitivities.py
```

The asset is a hypothetical 100 MW / 200 MWh battery with 87% round-trip
efficiency at the Hornsdale 275 kV connection point in SA1. It is not the
actual Hornsdale Power Reserve. Every figure is wholesale-energy only: FCAS,
contracts, caps, network support, outages, bidding behaviour and market impact
are excluded, so these numbers are a lower bound on what a real battery at this
connection point would earn and are not comparable to published total battery
revenue. See [BENCHMARKS.md](BENCHMARKS.md).

Dispatch is perfect-foresight within each 48-hour window, of which the first 24
hours are committed before the window rolls forward. That is materially easier
than dispatching against a real forecast, and it is not the same as annual
perfect foresight either.

## Reading these scenarios

The four A$25/MWh rows differ only in how the endpoints of the run are handled,
so they isolate endpoint effects from the arbitrage result itself.

The A$0 and A$50 rows bracket the headline degradation assumption. Degradation
cost is charged per discharged MWh and is the model's only cycling penalty, so
it sets both how hard the battery works and how hard the problem is to solve.
The A$0 case needed a documented solver tolerance; see
[VALIDATION.md](VALIDATION.md#solver-tolerance-and-where-exclusivity-binds).

## Caveats that apply to every row

- Revenue is settled at the regional reference price with dated marginal loss
  factors. There is no market-impact model: the battery is a price taker, which
  overstates achievable revenue for an asset of this size in a region this
  small.
- A single financial year is not a distribution. FY2022-23 contains the June
  2022 market suspension aftermath and an unusually volatile spring, and no
  claim is made that it represents a typical year.
- Degradation is a flat per-MWh charge, not a state-of-health model. It does not
  depend on depth of discharge, temperature, rate or age.
